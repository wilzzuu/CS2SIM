Feature: Roulette
- Player can choose 1-10 items from their inventory, get total value
- Generate "bots" that have 1-10 artificial items picked randomly with a reasonable value offset based on total player items' value
- Create a reel of all of the items that the bots and player has in a randomized order, keep track of who the item's belong by indexing the reel
- Animate the reel the same way as crate opening animation, this will decide who will win the roulette
- Chance of winning is calculated by the total value of every item in the current game divided by the total value of every player item in the current game
- If the animation lands on an item that is indexed for the player, the player wins the total value of every item in the current game
- If the animation lands on an item that is not indexed for the player, the player loses the items they chosen
- Button for starting the game

Considerations:
- Scroll view for viewing items in the current game
- The reel size should be 60, so the player item amount gets subtracted, and the remainder spread across randomly to as many bots as it takes to fill the 60 items cap, better if the remainder is not divided evenly
- Text indicator for chance of winning
- Text indicator of total value of game items
- Text indicator wether player wins or loses
- Player should be able to change selected items before starting the game
- Maybe have an item selector as the first thing that is displayed, then after player confirms the selected items with a button, generate bots and display the game view, where the player can see the game elements, like items that are in the current game.
- Player can go back to item selector with a button
- After the game ends, the end state is displayed, and the player can press a button to start a new game
