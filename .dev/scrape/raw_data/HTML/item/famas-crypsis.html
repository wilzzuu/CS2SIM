What's the difference between Factory New and Minimal Wear for the FAMAS | Crypsis?

What is the float value range for the FAMAS | Crypsis?

Float values in CS2 determine a skin's wear level on a scale from 0.00 (perfect) to 1.00 (maximum wear). With a float range of 0.00 to 0.55, this skin has specific wear availability that affects pricing. Lower float values within any condition category (e.g., 0.01 vs 0.06 in Factory New) result in cleaner appearances and typically command higher prices. For high-value trades, always verify the exact float value using inspection tools.
